# 样本统计

样本统计通过 `ontology::samples` 的类型与字段 Property 声明。主统计与补充统计都绑定具体来源字段，公开名称由模型定义。

均值统计非 NULL 样本，极值与求和遵循对应声明。样本有效次数字段只有在明确使用时参与计算，不默认加权。

Latest 选择最新合格整行，同节点的 CPU/内存共享选行，保留选中行的 NULL；它不代表最近一个非 NULL，也不等同于 Avg 或 Max。设备与服务器 CPU/内存具有 Latest 声明。

CPU、内存、在线率使用不同业务 newtype，保留共同展示尺度，不因此授予相加或互相比值的能力。跨主体、跨样本总体的统计需要关系与粒度证明。

`check-icloud-service.mjs` 从当前模型导出的样本声明获取查询地址，以不同来源字段上的不同数值构造独立预期，核对 181 个 Avg/Min/Max/Sum 统计及空总体；Latest 用独立设备时间序列验收。

执行命令见 [类型模型](TYPED_MIGRATION.md#验收)。
