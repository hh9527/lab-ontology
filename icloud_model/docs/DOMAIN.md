# IC 领域边界

模型从现有数据库与来源目录出发，通过类型和 Property 表达允许的业务查询空间。

- 身份、Reference 与外置 Relation 表达指代与连接；名称字段不自动成为身份
- 关系基数与连接键分别声明，数据表有同名字段不构成连接证明
- 称谓、指代、分类、指标各自具有显式查询能力
- newtype 限定代数能力；样本统计由模型声明，物理数字类型不自动允许 Sum
- 原始值字段保留 wire 表达，分类计算字段保留具名业务值；排序单独授权
- 同一主体可在多个数据集承载属性；统计总体与聚合规则属于具体承载场景
- 没有唯一性证据的来源表可发布字段与主体知识，但不虚构 grain
