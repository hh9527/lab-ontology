# 考核工具

本目录纳管三个文件：`tester-cli.mjs`、本说明和 `分析能力考核-IC卷.md`。临时拆题、运行配置、认证状态、轨迹和记录仅保留在本地，由仓库 `.gitignore` 排除。

需要 Node.js 22 或以上版本，无第三方依赖。由用户启动 dsh web，并准备独立的考生工作区。CLI 不启动、重启服务，也不清理考生文件。

```sh
cd testing
export TESTER_STATE_DIR="$PWD/.tester/10924"
node tester-cli.mjs auth 'http://127.0.0.1:10924/?token=...'
node tester-cli.mjs help
```

按需从考卷中提取本轮要发送的任务，写入临时题单，用 `=== T1` 等标记分段；只放任务正文，不放可澄清点和考核要点。渐进任务每次追加需求单独分段。临时题单不纳管，例如：

```text
=== T1
先来一件：统计最近 3 天的告警数量，按严重级别（紧急、重要、次要、提示）展示构成与总数。这个记作 T1。
```

```sh
node tester-cli.mjs sample \
  --cwd /absolute/path/to/candidate-workspace \
  --tasks tasks/current.md \
  --label current \
  --model deepseek-official/deepseek-flash
```

`sample` 显式接收题单，从完整考卷第二章读取定稿开场白，使用 CLI 内置的澄清应答策略，结果写入状态目录的 `samples/`。使用 `--no-auto` 可关闭自动应答。可选的 `TESTER_CONFIG_DIR/policy.json` 能覆盖内置策略，该配置不纳管。

不同端点使用独立 `TESTER_STATE_DIR`，避免混用认证和会话。默认状态目录是工具旁的 `.tester/`。采样需要持续运行的前台终端或宿主托管任务；每轮使用干净、专用的考生工作区。

```sh
node tester-cli.mjs sessions --cwd /absolute/path/to/candidate-workspace --model
node tester-cli.mjs use --newest --cwd /absolute/path/to/candidate-workspace
```
