# iMasterCloud 查询用例集（模板生成 · 对齐真实用户参考用例）

> 依据 [query-gen.md](query-gen.md) 的生成规则（过滤条件 + 遍历路径 + 查询目标），
> 对照 imaster-cloud 本体模型（compact-spec.md）填槽得到自然语言查询用例。
> 已结合 [user_query_cases_ref/](user_query_cases_ref/)（40 条真实用户查询 + 目标 SQL）优化，优化要点：
>
> 1. **实体类型细化**：把通用"网络设备/服务器/存储设备/PON设备"替换为真实子类
>    （网络交换机(LSW)、机架服务器、华为SMIS存储设备、光网络单元(ONU) 等），取值对齐参考用例；
> 2. **属性/取值真实化**：采用参考用例的真实表述与样例值
>    （软件版本 V200R019C10、设备版本 V200R001C00、资产位置 Beijing-A1-Rack01、MAC 00:1A:2B:00:00:00 等）；
> 3. **补齐参考中的遍历与表述**：新增"`{设备类型1}下连{设备类型2}上的告警信息`"（§7.4）、
>    "每个{设备类型}在{时间算子}的TOP3 {kpi}"、多条件+时间聚合（§6.5）等；
> 4. **词表扩充**：时间算子增加"最近7天/近一个月"，告警级别增加"提示"，与参考用例一致。
>
> 全部路径均经过合法性校验：`产生的` 仅对有 DataLink→EventSet 的实体、
> `的{子部件}` 仅对有 contains 关系的实体、`在{时间}{kpi}` 仅对有 DataLink→MetricSet 的实体、
> `下连` 仅对有 EntitySetLink→physical_link 的实体。
