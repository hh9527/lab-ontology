# 学习 Telora

本目标是与当前角色会话绑定的语言资质。完整阅读 `telora/docs/TELORA.md` 和
`telora/docs/TELORA-CLI.md`，并通过 `bin/telora` 实际确认后续任务需要使用的命令。

完成时应当能够：

- 阅读和编写当前实现支持的 Telora 源码；
- 理解 crate、module、import、bin、test 和 diagnostics 的边界；
- 使用 `run`、`check` 和 `query` 完成实现验证与知识发现；
- 依据实际诊断修正代码，不依赖未实现或旧版本命令。

该目标不产生业务文件。完成学习与必要的命令验证后，提交当前 session qualification。
