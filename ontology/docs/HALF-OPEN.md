# 非封闭来源与计算分类

来源编码不能映射到封闭业务空间时，保留原始字段，并发布平行的计算分类字段。完整声明方式见[字段映射](FIELD-MAPPINGS.md)。

原始字段保留来源 String／Int 及可空性。计算字段使用具名 enum，将已知来源 wire 映射到业务 variant，将未识别的非空来源映射到显式 Unknown。SQL NULL 保持 NULL，不与 Unknown 混同。

Unknown 不携带来源载荷；原始字段独立保留实际编码，查询可同时投影两列。业务计算、分类筛选与来源细节分别选择相应字段；计算字段的等值比较可下推为原始列的有限 IN 集合，未知条件排除 NULL 并匹配其余编码。

多个来源字段共享同一映射时，使用 `values::mapping` 和 `values::computed_domain`。不同来源编码集合分别声明；映射不隐式统一业务类型、分组许可或排序权限。

排序由 enum 的 `order_by_itag` 与互异整数标签声明。原始字段的存储顺序与计算分类的业务顺序分别处理。发现、codec 与查询校验消费同一份映射定义，展示标签不增加查询能力。
